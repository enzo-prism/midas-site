QUESTIONS

Providers,
answered.

How many AI providers does Midas support?

Midas 0.51.0 supports 52 providers. Codex, Claude, Cursor, Gemini, and Meta have guided setup; the rest are in Settings → Providers.

Do I need an API key for every provider?

No. Many providers reuse a sign-in you already have, such as a CLI login or browser session. Others, like OpenRouter or DeepSeek, need an API key that you add in Settings → Providers.

Can Midas show billed API spend?

Yes, for Anthropic with an organization Admin API key: it is labeled billed and never added to the AI Spend estimate. OpenAI organization costs from an Admin key appear on the OpenAI provider, also outside the estimate.

Which providers show spend estimates at API rates?

Codex, Claude Code, Cursor, Gemini (through Antigravity), and Meta’s Muse Code have local spend estimates. DGX Spark gets an API-equivalent value. How estimates work.

My provider isn’t listed. Can I request it?

Yes. Open an issue on the Midas GitHub repository with the provider and the usage it reports.
