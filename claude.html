01 / WHAT YOU SEE

Every Claude limit.
Its own bar.

5-hour and weekly limits

Each limit shows the percentage left and its reset time. Verified Ultra accounts, which no longer have a 5-hour limit, show only the weekly limit, with a note.

Saved limit resets

See how many saved resets you hold, which limit each one refills, and when it expires. You redeem them in Claude under Settings › Usage.

Personal and work accounts

Add each Claude account with an optional nickname. Each refreshes on its own and never borrows another account’s credentials.

Claude Code spend at API rates

Claude Code’s local transcripts, priced at Anthropic’s public API rates, including cache writes, cache reads, and fast mode. How estimates work.

Billed API spend, kept apart

Add an Anthropic Admin API key to see what your organization was billed. It’s labeled billed and never added to the estimate.

Model limits in details

Model-specific weekly limits, usage-credit state, and this week’s usage by product live in account details, out of the overview.

04 / QUESTIONS

Claude usage,
answered.

How do I see when my Claude limit resets?

Midas shows each Claude limit in your Mac menu bar with the percentage left and a reset countdown for each limit, so you can see when the 5-hour and weekly limits refill.

Does Midas track Claude Code usage?

Yes. Claude Code draws on the same 5-hour and weekly limits Midas shows, and Midas estimates Claude Code spend by pricing the tokens in its local transcripts at Anthropic’s public API rates.

Why does my Claude Ultra account show only a weekly limit?

Verified Claude Ultra accounts have had no 5-hour limit since October 30, 2026, so Midas shows only their weekly limit, with a note explaining why.

Can I track a personal and a work Claude account?

Yes. Add each one under Settings → Providers → Claude. Midas verifies the email, lets you set a nickname, and refreshes each account’s limits separately. Claude Code spend is estimated once for the whole provider, not per account.

Is the Claude spend in Midas what I pay?

No. It’s what your Claude Code tokens would cost at Anthropic’s public API rates, which shows the value of your usage, not a charge. Billed API spend from an Admin API key is shown separately and never added to the estimate.

Does Midas change my Claude Code login?

No. Adding or removing Claude accounts in Midas leaves your current Claude Code login unchanged.
