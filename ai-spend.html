AI SPEND · HOW IT WORKS

What your AI usage
costs at API rates.

Midas prices the tokens you use in Claude Code, Codex, and Gemini at public API rates, values Cursor usage from Cursor’s own reported costs, and adds it up in your Mac menu bar. It’s an estimate of value, never a bill.

UPDATED NOV 24, 2026 · MIDAS 0.52.0

01 / THE MATH

Tokens × list price.
Nothing more.

Recorded tokens×Public API rate=AI Spend (estimate)

Most AI subscriptions aren’t billed per token. AI Spend shows what the tokens you used would cost if you paid public API prices, so you can see the value of each plan and compare months.

02 / SOURCES

Where the tokens
come from.

Claude Code

Local Claude Code transcripts, priced at Anthropic’s API rates, including cache writes and reads, fast mode, US-only inference, and web searches. Claude tracker.

Codex

Local Codex session logs, with Fast mode priced at the Fast rate. Codex cloud adds up to 30 days of account-reported history. Codex tracker.

Cursor

Cursor uses its own reported costs, not API list prices. On unified plans, the daily usage feed reports tokens and billed cost, and plan-included usage is valued at the current week’s rate per token; legacy plans use per-request usage events. Cursor tracker.

Gemini

Local Antigravity transcripts, priced at Google’s public Gemini rates. Gemini tracker.

Meta

Muse Code terminal logs on your Mac, with plan readings when Meta reports them.

DGX Spark

Local vLLM tokens compared with a named hosted API rate: an API-equivalent value, not a bill or measured savings.

03 / THE RULES

Honest numbers.
Or none.

Missing is never $0

Usage Midas can’t price, like an unknown model or a gap in history, is left out and the total is marked partial.

Billed stays separate

Billed API spend from an Anthropic Admin key is labeled billed and never added to the estimate.

Currencies stay separate

Each provider keeps its original currency. Midas never silently converts.

Month by month

Compare cost or tokens across 6 or 12 months. History can load up to 365 days where the source keeps it.

Rates you can check

Public list rates come from models.dev, cached for 24 hours, with built-in fallback tables.

Not a savings claim

An API-equivalent value shows what usage is worth at list prices. It doesn’t claim what you saved.

04 / QUESTIONS

AI spend,
answered.

How much is my Claude subscription worth at API rates?

Midas answers that for your own usage: AI Spend prices your Claude Code tokens at Anthropic’s public API rates, so you can compare the figure with what your plan costs. It is an API-equivalent estimate, not a bill or a savings claim.

Is AI Spend my bill?

No. AI Spend is your recorded usage priced at public API rates. Subscription plans are not billed per token, and billed API spend from an Admin API key is shown separately.

Which prices does Midas use?

Public list rates from models.dev, cached for 24 hours, with built-in fallback tables. Claude pricing includes 5-minute and 1-hour cache writes, cache reads, fast mode, US-only inference, and web searches.

Why is my AI Spend total marked partial?

When Midas can’t price some usage, such as an unknown model or missing history, it leaves that usage out and marks the total partial instead of counting it as $0.

Does Midas convert currencies?

No. Each provider stays in its original currency, and Midas never silently converts between them.

How far back does spend history go?

Monthly charts cover 6 or 12 months, and Load up to 12 months sets a 365-day history window. Codex cloud supplies 30 days and Mistral only its current month, so older months for those sources show as unavailable.
