04 / GOOD TO KNOW

A few details.

Is token spend the same as my bill?

No. “Token spend (API rates)” estimates the value of usage at API prices. Subscription fees, credits, discounts, and provider billing can differ. Missing estimates are excluded, not treated as zero. Provider subscriptions and API charges are separate.

Which Macs can run Midas?

The current download supports Apple Silicon Macs running macOS 14 Sonoma or later. Download the ZIP, extract the app, and move it to Applications. The bundle still uses the CodexBar filename for compatibility.

Do all providers show remaining usage?

Only when the provider supplies a meaningful quota. Codex shows weekly remaining usage. Cursor uses its reported quota. Meta has no quota, so its ring stays neutral rather than inventing a percentage.

How do updates work?

Choose Check for Updates in the panel footer, then Download and Install & Restart. Current releases use Midas’s own signed Sparkle update channel. Automatic checks are available in Settings → About.
