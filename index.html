04 / QUESTIONS

Before you download.

Is “estimated spend” the same as my bill?

No. Midas prices your tokens at public API rates to show what that usage would have cost pay-as-you-go. Subscription fees, credits, discounts, and each provider’s billing rules are different. If an estimate is missing, Midas leaves it out and marks the total as partial instead of counting it as $0.

How does Midas put a dollar figure on Codex usage from my other Macs?

With Track all connected accounts on, Midas reads available Codex cloud token history for each connected account and combines it across computers. It prices those tokens with a blended rate taken from your recent priced local history. If it has no usable sample, the dollar figure stays unavailable. You can also set your own rate or show tokens only. Cloud history comes from private ChatGPT analytics endpoints, not an official billing API, so it can change independently of Midas.

Which Macs can run Midas?

Apple Silicon Macs running macOS 14 Sonoma or later. Download the ZIP, unzip it, and move the app to Applications. The bundle keeps the CodexBar filename for compatibility with existing settings.

Do all providers show remaining quota?

Only when the provider reports one. Codex shows weekly remaining, Cursor uses its reported quota, and Meta has no quota, so Midas shows a dashed ring rather than a made-up percentage. Quota percentages are never averaged across accounts or providers.

What is a banked reset?

Codex can grant on-demand rate-limit resets. Midas shows how many each connected account has available, separate from the scheduled weekly reset. Zero means none are available, Unavailable means no count was reported, and stale counts are labeled last known. Hover a row or expand account details to see reported expiry times.

What about Claude, Gemini, Copilot, and the rest?

Guided setup covers Codex, Cursor, and Meta. Every provider from the CodexBar foundation, including Claude, Gemini, GitHub Copilot, OpenRouter, Grok, Perplexity, and more than 40 others, stays available in Settings → Providers.

What leaves my Mac?

Midas talks to providers with the credentials you already have and never stores passwords. Provider logos are bundled, so opening the app makes no logo requests. Optional iCloud sharing sends only derived pricing samples between your own Macs (a rate, token counts, timestamps, a device identifier, and a hashed account-set identifier), never prompts, emails, or credentials, and they expire after 24 hours.

How do updates work?

Choose Check for Updates in the panel, then Download and Install & Restart. Releases are signed and notarized and delivered through Midas’s own Sparkle feed, which accepts only signed Midas builds. Automatic checks live in Settings → About.
